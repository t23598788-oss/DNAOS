# DNA OS brand files

This package contains two approved visual variants: the owner-supplied color artwork and a restrained monochrome rendition. Each has horizontal and square-mark files. The monochrome artwork is derived from the original logo transparency; it is not a retyped wordmark.

## Stable download locations

Base URL: `https://dnaos.dev/assets/brand/dna-os/v1/`

| Use | PNG | SVG wrapper |
| --- | --- | --- |
| Small document header, monochrome | `dna-os-horizontal-mono.png` | `dna-os-horizontal-mono.svg` |
| Original-color horizontal logo | `dna-os-horizontal-color.png` | `dna-os-horizontal-color.svg` |
| Square mark, monochrome | `dna-os-mark-mono.png` | `dna-os-mark-mono.svg` |
| Square mark, original color | `dna-os-mark-color.png` | `dna-os-mark-color.svg` |
| Asset manifest and checksums | `brand-assets.json` | — |

The horizontal files are 990 × 400 pixels. Square marks are 384 × 384 pixels with transparent padding. SVG files are self-contained and preserve the exact raster artwork.

Use DNA OS artwork only to identify DNA OS. A connected provider, service, or platform must use that provider's own approved mark. The generic DNA OS integration glyph is not a substitute for a provider logo.

## Source and preservation

The color source is `public/landing-preview/assets/dna-os-logo-transparent.png`, SHA-256 `92077471929c5d5e876ce995be381e8c43bcca3e39a60a6e7412d33941c07c19`. The supplied source bytes are retained unchanged. The old temporary brown mark is replaced at `/icons/logo-master.png` with the current D mark and matching source wordmark. It remains a review-only archive asset and is not part of this public brand kit.
