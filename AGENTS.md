## Mandatory DNA OS work admission

Before changing this repository, read `registry/AI_WORK_ADMISSION_POLICY.json` and identify the active DNA ID, repository, branch, commit, affected capability, and authoritative environment. Humans, AI agents, and automation follow the same gate; no role bypasses evidence or tenant/security boundaries.

Run `npm run ai:admission:test` and `npm run ai:admission -- --mode production` before proposing a production-bound change. Compare claims with the actual source and, when applicable, the live database catalog, applied migration history, and deployed runtime. Preserve unknowns as `UNVERIFIED` or `CONFLICT`; never turn a source declaration, successful build, screenshot, or design artifact into a claim of online verification. Production dependencies must have valid source hashes and verified runtime evidence. Do not store credentials, private connection strings, user data, or trade-secret calculations in evidence.
