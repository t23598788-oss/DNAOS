# DNA OS A4 — current layout

A4 portrait, 210 × 297 mm; horizontal margins 13 mm, top 22 mm.
Company branding at top; title/reference at left, date at right; four metadata
columns; item details below; amounts right aligned; memo and footer.

The bank screenshot is a positional reference only. No bank logo, building,
watermark, or bank-specific transaction information is included. Background is
plain white. Issuer/recipient signature rules and labels were removed as requested.

PDF text uses embedded Thonburi/Arial fonts. Exact reference font is unverified.
HTML falls back to embedded Noto Sans Thai if Thonburi is unavailable. Text and
rules are vector content, not a flattened image. See layout-tokens.json for sizes.

layout.html is the editable layout source; template.html includes embedded fallback
fonts and is the printable version. Export is output/pdf/dna-os-document-a4.pdf.
The blank watermark.svg is retired; it is not referenced by the template.

This is a presentation template with sample values, not an issued business document
or a production document-engine change.
