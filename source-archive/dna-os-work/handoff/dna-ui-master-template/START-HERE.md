# DNA OS — ชุดแม่แบบสำหรับนักพัฒนา

เปิด index.html เพื่อดูหน้าจอหลัก เอกสาร A4 และผู้ช่วย AI สี่รูปแบบ ส่ง ZIP ทั้งชุดให้นักพัฒนา

## ไฟล์
- workspace/index.html: สำเนาไฟล์ Sites ที่เผยแพร่ล่าสุดทุกไบต์ คง sandbox และ CSP
- documents/template.html: แม่แบบ A4 พร้อมฟอนต์ตามต้นฉบับ
- documents/layout.html และ layout-tokens.json: ซอร์สและค่าจัดหน้า
- assistants/characters.fragment.html: ซอร์ส HTML/CSS/JS ตัวละคร
- assistants/preview.html: ตัวอย่างภาพเคลื่อนไหว ข้อมูลงานเป็นตัวอย่าง

เอกสารถอดแถวลายเซ็นผู้รับ/ผู้ออกตามคำสั่งเจ้าของ ไม่มีการเพิ่มโลโก้หรือลายน้ำธนาคาร ข้อมูลและยอดเงินตัวอย่างต้องแทนด้วยข้อมูลจริงจากหลังบ้าน
ชุดนี้รวม assets และจุดเริ่มดูไว้ด้วยกัน ยังไม่ใช่ production app และยังไม่ได้ประกอบผู้ช่วยหรือเอกสารเข้ากับ workspace จริง

## คำสั่งให้นักพัฒนา
นำแม่แบบนี้ไปแปลงเป็น components ในโครงการเดิม ใช้หน้าตาที่เจ้าของเลือกแล้ว
ให้ /admin/relationships แสดง UI ใหม่โดยตรง ไม่ส่งมอบ iframe ครอบ UI เก่าหรือปุ่มกลับไปเครื่องมือเดิม
เชื่อม API/services/engines/auth/permission/ฐานข้อมูลเดิม ห้ามสร้างสูตรการเงินหรือ business engine ซ้ำ
ใช้ Railway service/domain เดิม ไม่สร้าง production อีกเส้น
ตรวจทุกจุดอ้างอิงและพิสูจน์หน้าจอใหม่ครบก่อนลบ UI เก่าที่ถูกแทนแล้ว ตรวจ imports/routes หลังลบ
เก็บ components กลางและ backend ที่ยังใช้งานร่วมกัน รายงานสิ่งที่ลบ เก็บ และยังต่อไม่ครบ
ย้อนกลับผ่าน Git ไม่เก็บ UI เก่าสองชุดที่เปิดใช้ควบคู่เป็นผลสุดท้าย
ห้าม commit/push/deploy หรือ apply LIVE migration ก่อนเจ้าของตรวจและอนุมัติ
