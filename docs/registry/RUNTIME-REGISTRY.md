# Runtime Registry

DNA OS keeps runtime/process concerns in existing modules such as:

- `control/runtime-control/` — LaunchAgent / supervisor vocabulary for declared services
- `control/runtime-endpoint-registry/` — endpoint declarations (must not treat vendor hosts as architecture authority)
- Owner Command HTTP transport health at loopback `:8791` when that process is running

This file indexes **existing** runtime registration concepts. It is not a
new central runtime registry product.
