- App shell
- Header
- System navigation

## Forbidden

Never use this mark as a substitute for:

- Google / Google Workspace
- Gmail, Calendar, Drive, Sheets
- Supabase, GitHub, Railway, LINE
- Meta / Facebook / Instagram / TikTok
- or any other external provider connection/integration card

When an external provider's official asset is missing, use the **neutral generic integration** SVG (`generic/dna-os-integration-generic.svg`), not this D mark.
